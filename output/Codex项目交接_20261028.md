## 1. 项目定位与约束

**一句话定位**：个人散户的无盯盘短线量化选股系统——每个交易日收盘后自动扫描全市场沪深主板，结合"市况分层 + 情绪判定 + 形态信号"输出次日操作建议（HTML 报告 + JSON）。

**硬性约束（用户偏好，必须遵守）**：

| 约束 | 值 |
|---|---|
| 投资者类型 | 个人散户，无盯盘时间（只能在收盘后决策） |
| 可投资范围 | A股 + 公募基金 |
| 股票范围 | 仅沪深主板（60/00 开头，排除 30 创业板 / 688 科创板 / 8/4 北交所） |
| 资金规模 | 约 1 万元，分散 5 只，每只 2000 元 |
| 股价上限 | 收盘价 <= 20 元（保证 2000 元可买 1 手：20×100=2000） |
| 收益口径 | T 日收盘买入（尾盘），T+1 收盘卖出（r1）；双边成本 0.3%（0.15%×2） |
| 验收标准 | N>=30 且 扣成本后胜率>=55% 且 扣成本平均 r1>0 |
| 可成交性过滤 | 信号日当日涨幅 >8% 或一字涨停（open==high==low==close 且涨停）判定不可买，样本剔除 |

## 3. 系统架构

### 3.1 每日流程（daily_pick.py，15:20 定时任务自动运行）

```
启动（--no-update 为快速测试模式）
 │
 ├─ 1. 增量更新：thsdk 拉最近 8 个交易日日K（UPDATE_DAYS=8，失败降级用缓存）
 ├─ 2. 市况判定：mkt_state_daily.build_index（等权指数）→ 最新行 → dev/state/depth
 ├─ 3. 情绪采集：mkt_sentiment.main()（涨停结构/人气榜/舆情/股吧，失败置 None）
 ├─ 4. A2 信号全量扫描：全缓存主板股，与回测定义一致
 ├─ 5. 门控 gate_verdict：verdict 含「空仓/反弹脉冲/追高」→ 仅观察名单 watch_only
 ├─ 6. HTML 报告：ECharts CDN 单文件自包含 → output\每日选股_YYYYMMDD.html
 └─ 7. 落盘 JSON：temp\daily_pick_latest.json（供后续读取/自动更新）
```

| `mkt_sentiment.py` | 情绪采集：涨停结构、东财人气榜、财联社/华尔街见闻舆情、股吧人气榜 AES 解密、情绪评分 |

## 4. 市况匹配器规则（mkt_state_daily.py）

### 4.1 指数与状态定义

- **等权指数**：1649 只主板股日涨跌幅等权平均 → 累计净值（普涨普跌视角，避免权重股失真）
- **状态**：`指数 > MA20 且 MA20 上行 = 牛`；`指数 < MA20 且 MA20 下行 = 熊`；其余 = 震荡
- **深度分层**（dev = 指数/MA20 - 1）：
  - 深熊：dev < -6%
  - 中熊：-6% ~ -3%
  - 浅熊：-3% ~ 0
- **辅助指标**：ret5 / ret20（近5/20日等权指数涨跌）、mkt_ma5、MA60

### 4.2 市况分布（2022-2026 五年，iter2 统计）

| 市况 | 交易日数 | 占比 |
|---|---|---|
| 牛 | 567 | 49.6% |
| 浅熊 | 201 | 17.6% |
| 震荡 | 191 | 16.7% |
| 中熊 | 124 | 10.8% |
| 深熊 | 61 | 5.3% |

### 4.3 A2 窗口判定（a2_window_judge，含情绪修正）

| 条件 | 判定 |
|---|---|
| 熊 + dev<-6% + r20<-8% + 情绪冷淡/恐慌 | 深熊+急跌+恐慌出清：A2 舒适区可精选介入（**注意：该结论已被迭代版推翻，见 §5**） |
| 熊 + dev<-6% + r20<-8% + 情绪亢奋 | 短线脉冲特征，追高危险，仅做最强龙头轻仓 |
| 熊 + r5<-3% + 情绪亢奋 | 反弹脉冲特征，追高易套，暂空仓等企稳 |
| 熊 + r5<-3% | 中熊档胜率仅 37%，需等 5 日企稳，暂空仓 |
| 熊（缓跌） | 空仓观望 |
| 震荡 + r5<0 | 谨慎，只做最强信号 |
| 牛 / 牛+亢奋 | 可正常参与 / 分批轻仓防回撤 |

情绪强度归类：hot = score>=6 或 label∈{亢奋,偏热}；cold = score<=-2 或 label∈{恐慌,冷淡}。

### 4.4 情绪背离检测（sentiment_divergence）

- 熊 + 亢奋 → 「市况熊+情绪亢奋：短线脉冲反弹特征，追高易套，纪律等企稳」
- 牛 + 冷淡 → 「人气未跟上，反弹持续性存疑，轻仓试错」
- 震荡 + 亢奋 → 「情绪先于指数，防冲高回落」

### 4.5 情绪评分规则（mkt_sentiment.py，范围 -6 ~ +6）

| 因子 | 加分规则 |
|---|---|
| 涨停家数 | >=60 +2；>=30 +1；<15 -1 |
| 跌停家数 | >=30 -2；>=10 -1 |
| 炸板率 | <=15% +1；>=35% -1 |
| 连板高度 | max>=5 +2；>=3 +1 |
| 股吧人气榜涨停家数 | >=5 +1；>=3 +1 |
| 股吧热度最高分 | >=2000万 +1 |

label 映射：6/5/4=亢奋，3/2=偏热，1=活跃，0=中性，-1=偏冷，-2=冷淡，-3~-6=恐慌。

## 5. 策略结论与门控路由（最重要）

### 5.1 回测口径（两版报告统一）

- 样本：初版 2024-01~2026-10（两年）；迭代版 2022-01~2026-10（五年，kline_day_long_v2）
- 收益：T 收盘买入，T+1 收盘卖出，扣双边成本 0.3%；含涨跌停不可成交过滤
- 稳健性纪律：凡胜率显著高于基准（弱势市基准 40~45%），必须按月 groupby 检查样本集中度并做剔极端月检验（2024-02 救市反弹、2022-05 深跌反弹）

### 5.2 结论速览

| 市况 | 结论 | 依据 |
|---|---|---|
| 深熊 | **A2 禁用** | 2022-2026 五年验证：A2 深熊仅 2024 年触发 96 次（95 次全在 2024-02，胜率 91.7%）；2022 年 6 次胜率仅 16.7%；其余年份 0 次。94.7% 高胜率完全由 2024-02 单月反弹贡献，单月依赖不可修复 |
| 中熊 | **默认空仓** | 所有候选（A2 家族、超跌+情绪分层、提纯网格、打分高分组）剔反弹月后均无稳定正期望；上一版「中熊冷淡+深超跌企稳 N=63 胜率 58.7%」在扩展样本后瓦解（依赖 2024-02） |
| 浅熊 | **B4 超跌企稳 + 情绪亢奋 + 打分>=5**（推荐落地） | 剔反弹月 N=84 胜率 60.7%，净收益 +0.535%/笔；2026 年新鲜样本 N=51 胜率 66.7% |

### 5.6 关键负向结论（避免 Codex 重走弯路）

1. **A2 家族在中熊/浅熊全面负期望**：中熊各变体胜率 33~42% 扣成本全负；A2 的"涨停次日缩量"逻辑只在该月 beta 中有效。
2. **超跌反弹无条件版不可用**：全量胜率 80~87% 是假象，63~82% 样本集中在 2024-02，剔月后 42~45% 转负。
3. **扩样本不是单月依赖的解药**：扩展到五年后依赖月从 2024-02 变为 2022-05+2024-02 两个，分月剔除检验才是正确方法。

5. **65% 目标不可达**：提纯网格上限 63.6%（bias<=-15，N=33 样本过小）；打分 5 分组 60~63% 是"胜率-样本"平衡点；65% 需 N<15 不可验证。
