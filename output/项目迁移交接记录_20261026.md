## 二、分析项目

### 2.1 v9 七因子周频策略（当前主线）

复刻自 GitHub `a-share-quant-v9` 的七因子量价打分 + 广度择时，改为周频：

- **七因子**：shrink_up（缩量上涨占比10周）、amount_20d（20周均量，负向）、max_up_20d（20周最大涨幅，负向）、expand_down（放量下跌占比10周）、tail_return（20周尾盘强度，负向）、vol_chg_std（20周量比波动，负向）、overnight_gap（20周跳空均值，负向）
- **打分公式**：`score = (shrink_up - amount_20d - max_up_20d + expand_down - tail_return - vol_chg_std - overnight_gap) / 7`，各因子截面 rank 归一化到 [-1, 1]
- **交易规则**：每周五截面打分选 TopN，下周一开盘买入，周五收盘卖出（一周持仓）
- **广度择时**：当周全市场上涨家数占比 `breadth = mean(pct>0)`；原版为广度高时进场（gt），**实测反向（lt，广度低于阈值时进场）显著更优**
- **优化结论（3年周K，2022-04 ~ 2026-10，全市场1650只主板）**：
  - Top4 + 反向择时(广度≤0.45)：3年累计 **+24.5%**，年化 **5.2%**，回撤 **-4.4%**
  - 2026 弱市：反向择时 +14.0% vs 全市场基准 -3.9%
  - Top10 + 反向择时(≤0.48) 亦可作为稳健档
- **最新候选（2026-42周）**：603293 / 603435 / 603459 / 001365 / 001239

## 六、关键踩坑记录

1. **因子计算**：`g[[]].apply` 索引不对齐会致因子全 NaN，必须用 `cond.groupby(code).transform` 修复
2. **周标识**：`yw` 按字符串排序会错乱，需用 `pd.to_datetime` 日期排序
3. **腾讯接口**：需要 sh/sz 前缀；缓存 key 为纯6位数字代码
4. **数据清理**：拉取失败的股票返回 `ERR` 标记行，回测前需 `df[df['close'].notna()]` 过滤
5. **断点续传**：fetch 脚本每批落盘，中途中断不丢数据
